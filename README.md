# val-futbol

Userscripts de Tampermonkey del análisis de fútbol de Val (Sofascore + Playdoit). Se actualizan solos desde aquí.

Instalar una vez (abrir cada enlace con Tampermonkey activo y pulsar "Instalar" o "Reinstalar"):

- Panel de Val: https://raw.githubusercontent.com/xXValdiXx/val-futbol/main/val-panel.user.js
- Panel de Val · Extras: https://raw.githubusercontent.com/xXValdiXx/val-futbol/main/val-extras.user.js
- Panel de Val · En vivo: https://raw.githubusercontent.com/xXValdiXx/val-futbol/main/val-vivo.user.js

Tampermonkey revisa si hay versión nueva (por defecto cada día) y la instala cuando sube el número de `@version`.
